# 🧩 OOP-Spring-2025

> C++ code from the **Object-Oriented Programming** course at **QAU, Islamabad**  
> Spring 2025 · 100% C++

---

## 📚 Topics Covered

| Topic | What's in it |
|---|---|
| **Classes & Objects** | Defining classes, member functions inside/outside class, employee & student classes |
| **Constructors** | Default, parameterized, copy constructor, constructor overloading, initializer list |
| **Memory Management** | Dynamic arrays (1D & 2D), creating objects with `new`, `const` keyword |
| **`this` Pointer** | Lab tasks using `this` |
| **Recursion** | Factorial, Fibonacci, power, sum of digits, print sequences, divide & conquer |
| **Operator Overloading** | `+`, `-`, `*`, assignment `=`, friend functions for overloading |
| **Inheritance** | Animal→Dog, Shape→Rectangle hierarchies, base class without virtual |
| **Virtual Functions** | Virtual vs non-virtual, polymorphism |
| **Templates** | Function templates, class templates, bubble sort with templates |
| **Friend Functions** | Temperature class example |
| **File Handling** | Read/write text & binary files, append, copy, delete, rename, `seekg`/`tellg`, word/char/line counting |

## 🚀 How to Run

```bash
git clone https://github.com/ehhsen/OOP-Spring-2025.git
cd OOP-Spring-2025

# Compile any file
g++ filename.cpp -o output
./output
```

> No dependencies — just a C++ compiler (g++ / MinGW / clang++).

---

## 📁 Structure

All files are in the root — no subfolders.  
Lab tasks are prefixed with `LAbtask` / `LabTask` / `LABTASK`.  
Practice files are named by concept (e.g., `operator_overloading_...`, `recursive_...`).
